# Student Performance Prediction 🎓

## Project Description
Student Performance Prediction is a beginner-friendly Machine Learning project that estimates students' exam scores based on different academic and lifestyle factors.

The project uses student data such as daily study hours, attendance percentage, previous exam scores, and sleep hours to train a Random Forest Regression model.

## Objectives
- Analyze student performance data.
- Clean missing and inconsistent data.
- Understand the relationship between study habits and academic performance.
- Build a Machine Learning regression model.
- Predict exam scores for new student records.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Machine Learning Algorithm
Random Forest Regression.

## Dataset
The dataset contains 203 synthetic student records with five columns, including student ID and four student-related features.

## Project Workflow
1. Data collection
2. Data cleaning and preprocessing
3. Feature selection
4. Train-test splitting
5. Model training
6. Model evaluation
7. Exam score prediction

## Disclaimer
The final exam scores used for training are simulated for educational purposes. The model is a learning demonstration and has not been validated using real exam results.
